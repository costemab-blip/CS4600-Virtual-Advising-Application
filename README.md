# CS4600-Virtual-Advising-Application
This Project aims to create a functional advising application that allows students to enter in their advisement report, and generates a reccommended path to graduation that stores different options. 

## Required tools:
* .NET SDK (dotnet 10)
* node.js and npm 
* The Angular Cli -> Run ```npm install -g @angular/cli ```
* An IDE of your choice. (I like Visual Studio)

  ### How to install:
  1. install the [dotnet 10 sdk](https://dotnet.microsoft.com/en-us/download)
     * you can check if you already have it installed by running ```dotnet --version``` in a terminal window
  2. install node.js and npm
     * Check Installation: ``` node -v
      npm -v ```
  3. install the Angular CLI
     * Run ```npm install -g @angular/cli ``` in a PowerShell window
